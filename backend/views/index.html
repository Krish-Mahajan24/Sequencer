REST API Route Directory

Method Endpoint Auth Description
POST /api/auth/signup Public Register new account on MongoDB Atlas
POST /api/auth/login Public Authenticate and receive JWT token
GET /api/auth/me JWT Bearer Get current authenticated user profile
PUT /api/auth/profile JWT Bearer Update user first name, last name, or email
PUT /api/auth/password JWT Bearer Change user account password
DELETE /api/auth/account JWT Bearer Cascade delete user account and music data
GET /api/tracks Optional Get user tracks / seed demo library
POST /api/tracks JWT Bearer Add new track with tempo, energy & mood
PATCH /api/tracks/:id/like JWT Bearer Toggle track liked status
PUT /api/tracks/:id JWT Bearer Update track parameters
DELETE /api/tracks/:id JWT Bearer Delete track from user library
GET /api/playlists JWT Bearer Fetch user's playlists
POST /api/playlists JWT Bearer Create and save a new playlist
DELETE /api/playlists/:id JWT Bearer Delete playlist
GET /api/sequences JWT Bearer Fetch saved mood transition sequences
POST /api/sequences JWT Bearer Save generated sequence with flow metrics
DELETE /api/sequences/:id JWT Bearer Delete sequence
GET /api/history JWT Bearer Get recent playback history
POST /api/history JWT Bearer Record played track
DELETE /api/history JWT Bearer Clear song playback history
